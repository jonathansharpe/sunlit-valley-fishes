# Society: Sunlit Valley Fish Radar

## What the heck is even this?

This simple program will help you on your fishing endeavors while playing the Society: Sunlit Valley modpack for Minecraft. It's hard to keep track of what fish are catchable when, so this program is here to help! The program will prompt the user to either enter in the current conditions, like season, weather, etc., or a specific fish they'd like to catch (options provided) and then the conditions required to catch said fish will be returned.

## Wait, isn't this already in the game?

Yes it is!

## So why does this exist?

I have been playing through this modpack, and I wanted to start a new side project in a new programming language, so I chose Rust and threw this together. I think I understand how Rust works, but it's complicated so I may need to do another project or two to get a good handle on it.

It could also be slightly more convenient for like 2 other people to load up their terminal and launch this program instead of spending ~80,000 to get the book that shows when each fish spawns and however much else for a fish radar.

## How do I run it?

Make sure Rust is installed on your system! Clone the Git repo like any other, find the executable in the `releases` folder, and do `./sunlit-valley-fishes` to launch it.

## Is the information here 100% accurate?

It should be! I used the picture guide that was posted on the Society: Sunlit Valley Discord server, and aside from updating one of the fish names from `Snowflake` to `Frosty Fin`, I haven't made any other changes. I should open up the game and verify all this info tbh...
