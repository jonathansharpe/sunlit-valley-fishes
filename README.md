# Fish Radar for *Society: Sunlit Valley* (Minecraft modpack)

## What is it?

This simple program will help you on your fishing endeavors while playing the Society: Sunlit Valley modpack for Minecraft. It's hard to keep track of what fish are catchable when, so this program is here to help! The program will prompt the user to either enter in the current conditions, like season, weather, etc., or a specific fish they'd like to catch (options provided) and then the conditions required to catch said fish will be returned.

## How do I run it?

Make sure Rust is installed on your system! Clone the Git repo like any other, find the executable in the "Releases" tab, download it, and run `./sunlit-valley-fishes` to execute it.
